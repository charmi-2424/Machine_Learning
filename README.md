# Machine Learning Portfolio

A curated collection of machine learning projects, exploratory data analysis (EDA), predictive models, and interactive web applications.

---

## 🚀 Projects

### 1. [❤️ Heart Disease Risk Prediction & Web App](./Heart/README.md)
- **Path**: [`Heart/`](./Heart/)
- **Tech Stack**: Python, Scikit-Learn, Streamlit, Pandas, Joblib
- **Model**: K-Nearest Neighbors Classifier (**86.4% accuracy**)
- **Description**: An interactive risk assessment tool for heart disease based on clinical indicators. Includes automated feature scaling, a confidence meter, health stat summary cards, and a plain-language medical glossary.
- **Documentation**: See [Heart/README.md](./Heart/README.md) for full setup instructions and medical feature details.

### 2. 🚗 Car Price Prediction
- **Files**: [`car_price.ipynb`](./car_price.ipynb), [`ford.csv`](./ford.csv)
- **Description**: Regression analysis predicting vehicle sale prices based on mileage, engine size, fuel type, and year of manufacture.

### 3. 📺 Advertising Sales Prediction
- **Files**: [`Advertising.ipynb`](./Advertising.ipynb), [`Advertising (2).csv`](./Advertising%20(2).csv)
- **Description**: Regression modeling assessing the impact of advertising budgets (TV, Radio, Newspaper) on product sales.

### 4. 🏥 Health Insurance Cost Prediction
- **Files**: [`Insurance.ipynb`](./Insurance.ipynb), [`insurance (1).csv`](./insurance%20(1).csv)
- **Description**: Predictive modeling of personal healthcare expenses based on age, BMI, smoking habits, and region.

### 5. 🚢 Titanic Survival Classification
- **Files**: [`titanic.ipynb`](./titanic.ipynb)
- **Description**: Classic classification problem predicting passenger survival using demographic and voyage variables.
